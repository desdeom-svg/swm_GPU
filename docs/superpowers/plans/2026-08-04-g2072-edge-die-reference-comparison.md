# G2072 Edge Die Reference Comparison Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a cloned G2072 Recipe without the two three-Die edge groups, verify that the old SWM loads it, and report physical-coordinate-aligned reference-image differences against the complete Recipe on the new SWM.

**Architecture:** Preserve the original Recipe and create a sibling clone whose TestPlan excludes the six identified edge Dies. Re-plan the clone through the upper-machine Recipe workflow so ScanSequence, FovMap, and ImageCount agree. Run each DLL in a separate process, extract one normalized record per FOV, and join records by current-image physical center rather than global index.

**Tech Stack:** Windows PowerShell, .NET Framework SWM DLL reflection, AutoReviewSystem.Data, XML Recipe files, `D:\新程序` upper-machine Recipe workflow.

## Global Constraints

- Never modify `D:\Config\Recipe\G2072A00_ME_DEP`.
- Clone target is `D:\Config\Recipe\G2072A00_ME_DEP_NoEdge3Die`.
- Remove exactly `(-1,-14)`, `(0,-14)`, `(1,-14)`, `(-1,14)`, `(0,14)`, `(1,14)` from the clone TestPlan.
- Use old DLL `D:\新程序\算法备份\旧版本\SWM.dll` and new DLL `D:\新程序\SWM.dll`.
- Compare reference images by physical FOV centers; global indexes are expected to shift after re-planning.
- Do not replace deployed DLLs during comparison.

              'ref1_global','ref1_center_x','ref1_center_y',

- [ ] **Step 2: Run the self-check before the exporter exists**

Expected: missing-file failure.

- [ ] **Step 3: Implement the exporter**

In a fresh PowerShell process, load dependency DLLs followed by the requested SWM assembly, call `Parameters.GetParam(byte[])`, and read private static `tt` and `modeSetting` through reflection. For every `ScanPlan.Slices[slice].Scans[scan]`, emit:

```powershell
[pscustomobject]@{
    dll = $DllPath
    recipe = $RecipePath
    global_index = $scanObject.Index
    slice = $sliceIndex
    scan = $scanIndex
    center_x = [math]::Round($scanObject.Area.X + $scanObject.Area.Width / 2, 6)
    center_y = [math]::Round($scanObject.Area.Y + $scanObject.Area.Height / 2, 6)
    ref1_global = $ref1Index
    ref1_center_x = $ref1CenterX
    ref1_center_y = $ref1CenterY
    ref2_global = $ref2Index
    ref2_center_x = $ref2CenterX
    ref2_center_y = $ref2CenterY
    mode = $imageRects[$scanIndex * $number + 24]
    active_trigger = $triggerMap.ContainsKey($scanObject.Index)
}
```

Use `ImageRects[scanIndex * number + 21]` and `+22` as row-local ref indexes, converting them back to global indexes with the slice's first global index.
